# Personal Finance — локальный финансовый PWA «Мои финансы»

Личное приложение для учёта денег: **iPhone + Windows, офлайн, без сервера, без аккаунта, без платных сервисов.**

**Статус: локальный MVP реализован и опубликован** — <https://maxgloshin.github.io/Financial/>.
Все данные хранятся только в IndexedDB браузера устройства.
Синхронизации между устройствами нет — перенос данных через резервные копии (JSON).

## Что уже работает (этап 1 — локальный MVP)

- **Счета:** наличные, дебетовые, накопительные, кредитки (лимит, долг, доступный лимит).
- **Операции:** расход, доход, перевод, погашение кредитки, возврат долга, возврат товара, корректировка.
- **Двойная запись:** каждая операция — набор проводок, сумма всегда 0. Балансы выводятся, а не хранятся — расхождение невозможно.
- **Деньги в целых копейках** (integer minor units), без плавающей точки.
- **Переводы и погашения не попадают** в доходы/расходы статистики.
- **Идемпотентность:** повторная отправка одного `clientRequestId` не создаёт дубль.
- **Undo:** удаление и правки отменяются из уведомления; мягкое удаление сохраняет историю.
- **Быстрый ввод:** сумма (со встроенным калькулятором `1200+350`), категории-чипы, запомненный счёт, авто-дата/время.
- **Обзор:** свои деньги, наличные/дебет/долг кредитки, бюджет месяца, средний расход в день, прогноз, ближайший платёж, ближайшее поступление (ожидаемые доходы никогда не попадают в баланс), «можно ли купить?».
- **Бюджет, планы, цели, долги** с отдельным учётом (возврат долга — не доход).
- **Резервные копии:** JSON-экспорт/импорт, контрольная сумма, проверка структуры (zod) и ссылочной целостности, режимы «заменить» и «добавить недостающее», шифрование AES-GCM + PBKDF2 (210 000 итераций) по желанию — пароль нигде не хранится.
- **Онбординг** из 3 шагов; все введённые значения потом редактируются.
- **PWA:** офлайн после первой загрузки (Service Worker), установка на главный экран iPhone/Android, тема светлая/тёмная/системная, обновление по запросу пользователя (без silent-reload, данные не теряются).
- **Демо-данные** — только вымышленные, загружаются вручную в настройках; в коде нет личных сумм.

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Сборка и проверка production-версии:

```bash
npm run build      # tsc + vite build → web/dist
npm run preview    # http://127.0.0.1:4173
npm test           # Vitest: 28 тестов (деньги, калькулятор, финансы, БД, бэкап)
npm run typecheck
```

Требуется Node.js ≥ 22.18.

## Установка на iPhone

1. Откройте сайт в **Safari** (не в другом браузере).
2. «Поделиться» → «На экран Домой».
3. Запускайте с иконки — тогда работает офлайн-режим.
4. Делайте резервную копию и сохраняйте файл в «Файлы»/iCloud Drive.

Важно: Safari и установленное PWA на iOS могут иметь **разные хранилища** — выберите одно и не переключайтесь без экспорта.

## Публикация на GitHub Pages

Опубликовано: <https://maxgloshin.github.io/Financial/> (репозиторий <https://github.com/MaxGloshin/Financial>).

- GitHub Actions (`deploy.yml`): `npm test` → build с `VITE_BASE=/Financial/` → deploy в Pages.
- CI (`ci.yml`): typecheck, тесты и сборка на каждый push и pull request.
- Маршрутизация — HashRouter, поэтому 404-редиректы не нужны; `.nojekyll` в комплекте.
- HTTPS выдаёт GitHub автоматически; Service Worker кеширует оболочку, приложение открывается офлайн.

## Ограничения текущей версии

- Нет синхронизации между устройствами (перенос — только файлом резервной копии).
- Резервная копия — вручную; приложение напоминает, если копии нет или она старше 7 дней.
- На iOS Safari и установленное PWA — разные IndexedDB.
- Забытый пароль зашифрованной копии восстановлению не подлежит.
- `server/` (Fastify/SQLite) сохранён как legacy-справочник и не используется локальным приложением.
